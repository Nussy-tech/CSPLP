Learning Areas

Introduction to Computers

Learn the meaning, characteristics, and importance of computers in everyday life.

Computer Hardware

Understanding the physical components of a computer system.

Computer Software

Explore system software and application software used to perform tasks.

Input Devices

Learn how devices such as keyboards, mice, and scanners enter data into computers.

Output Devices

Understand devices that present information from the computer to users.

Storage Devices

Discover how computers save and retrieve information using various storage media.

Operating System

Learn about the software that manages computer hardware and applications.

Computer Networks

Understand how computers communicate and share resources through networks.

Internet

Explore online communication, information sharing, and digital services.

Computer Security

Learn how to protect computers, data, and users from digital threats.

Research Objectives

Purpose of the Study

  • ✔ Determine students' achievement before the intervention.
  • ✔ Examine the effect of personalized analogies on learning.
  • ✔ Compare learning outcomes between groups.
  • ✔ Evaluate students' perceptions of the learning approach.
  • ✔ Generate data for educational research.
